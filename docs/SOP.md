# Hanemann Plastic Surgery — Website Guide for Office Staff

A plain-language guide to understanding the website and making everyday edits.
You do **not** need any technical knowledge to use this. If anything here is
unclear or something looks broken, contact **Crescendo Media** — don't worry,
you can't break the website by editing text or photos.

**Website:** https://hanemannplasticsurgery.com
**Last updated:** June 2026

---

## 1. How the website is set up

There are two sides to the website:

1. **The public website** — what patients see (Home, About, Procedures, Gallery,
   Contact, the Resources articles, etc.).
2. **The admin area** — a private, password-protected section where you make
   edits, view patient inquiries, manage before/after photos, and see traffic.

You reach the admin area by logging in. Once you're logged in, you can edit much
of the public website **right on the page**, and you have an **Admin Dashboard**
for everything else.

---

## 2. Logging in

1. Go to **https://hanemannplasticsurgery.com/admin/login**
2. Enter the office email: **Drh@hanemannplasticsurgery.com**
3. Enter the password (ask your administrator if you don't have it — for security
   it isn't written down in this guide).

Once logged in, you'll see a small **"ADMIN EDIT"** tab on the **right edge** of
the screen. That tab is your control panel.

> 🔒 Always log out on shared computers. The admin area is for staff only.

---

## 3. Editing text and photos on the page

This is the easiest and most common task — changing wording or swapping a photo.

1. Log in (Section 2).
2. Click the **"ADMIN EDIT"** tab on the right edge of the screen. A panel opens.
3. Make sure **Edit Mode** is turned **ON** (the switch is green). When it's on,
   small **edit buttons** appear next to the text and images you're allowed to
   change. (Turn it **OFF** anytime to preview the page the way patients see it.)
4. Browse to the page you want to change.
5. **To edit text:** click the edit button next to the text, type your change,
   and confirm. It saves to the live website automatically.
6. **To replace a photo:** click the edit button on the image and upload or pick
   a new one.

**Tips**
- Changes are **live** — once you save, patients see them. Re-read before saving.
- Keep wording consistent with the brand (professional, warm, Baton Rouge).
- If an item has **no** edit button, it isn't editable from the page — contact
  Crescendo Media for that change.

### Home page main (hero) images
The large rotating images at the top of the home page have their own controls.
In the **ADMIN EDIT** panel → **Settings**, use **"Edit Desktop Hero"** and
**"Edit Mobile Hero"** to upload a new image or reposition it. Set both desktop
and mobile so it looks right on phones too.

## 4. The Admin Dashboard

For everything beyond on-page text/photos, open the **Admin Dashboard**
(from the ADMIN EDIT panel's **Navigate** option, or go to
`https://hanemannplasticsurgery.com/admin/dashboard`). It has these tabs:

| Tab | What it's for |
|---|---|
| **Inquiries** | Consultation & contact requests from patients (Section 5). |
| **Schedule** | Scheduling view. |
| **Analytics** | Website traffic and visitor numbers (Section 7). |
| **Blog** | The "Resources" articles. |
| **PDFs** | Downloadable files such as the patient-forms PDF. |
| **Photos** | The before/after gallery (Section 6). |

## 5. Patient inquiries (consultation requests)

Every time a patient submits the **Schedule a Consultation** or contact form, it
lands in the **Inquiries** tab.

- Each inquiry shows the patient's **name, contact info, what they're interested
  in, their message, and the date + time** it came in (newest first).
- Set each inquiry's status to **"Contacted"** once your team has reached out, so
  you can tell at a glance what's still new.
- Use the **trash/delete** button to remove obvious spam or test submissions.

> 💡 Respond quickly — these are real leads. The Analytics tab also counts these
> as "Inquiries" so you can see how many you're getting over time.

## 6. Before / After Gallery (Photos tab)

To add or manage gallery cases:

1. Admin Dashboard → **Photos**.
2. **Add a case:** choose the **category and procedure** (e.g. Breast → Breast
   Lift), then upload the **before and after** photos.
3. **Multiple angles:** a case can have several **views** (front, side, etc.).
   Use the per-view **Replace** and **Remove** buttons to manage them.
4. **Set the order:** each case has a **position dropdown** ("Pos 3 / 12"). Pick
   the number to place that case where you want it in the list. The patient-
   facing case numbers follow the order you set.

**Photo tips**
- Use clear, consistent, well-lit before/after photos.
- Make sure you have proper patient **consent** before posting any photo.
- Crop before/after to match each other for a clean look.

## 7. Website traffic (Analytics tab)

The **Analytics** tab shows **real, live** visitor data for the site.

- **Date range:** use the buttons at the top — **Today, 7d, 30d, Since launch,
  All** — or click **Custom** to pick exact dates on a calendar. Everything
  updates to that time window.
- **The cards show:**
  - **Active Now** — people on the site in the last 30 minutes.
  - **Sessions** — visits in the selected range.
  - **Page Views** — pages viewed in the range.
  - **Inquiries** — consultation requests in the range (with conversion %).
- **Below that:** your most-visited pages, where visitors came from (Google,
  Facebook, direct, etc.), and what devices they used (mobile/desktop/tablet).

> The numbers are live and update automatically. If you just launched or picked a
> very short range, small numbers are normal.
>
> For deeper reports — **age, gender, interests, and detailed location** — those
> live in **Google Analytics** (a separate Google tool), not this tab. Ask
> Crescendo Media for access if you'd like to see them.

## 8. Articles / Resources (Blog tab)

  articles or formatting help, loop in Crescendo Media.

## 9. Patient forms & other PDFs

- Anything that looks broken or shows an error
- New staff logins or removing someone's access

## 11. Quick FAQ

**Will my edit show up right away?**
Yes — page text/photo edits are live as soon as you save. Re-read before saving.

**Can I break the site by editing text?**
No. Editing text and photos is safe. If something looks off, turn Edit Mode off
to preview, or contact Crescendo Media.

**I don't see edit buttons.**
Make sure you're logged in and **Edit Mode** is ON in the ADMIN EDIT panel. If a
specific item still has no edit button, it isn't editable from the page —
contact Crescendo Media.

**A patient says a button/link doesn't work.**
Note the page and what they clicked, and send it to Crescendo Media.

**Who do I contact for help?**
**Crescendo Media** handles all the behind-the-scenes/technical work and any
change not covered above.
